# 🤖 AI Chatbot – Python Project

## 📌 About the Project

This is an AI-powered chatbot project developed using Python. It aims to explore conversational AI and provide intelligent responses to user queries.

The project is organized into different Python files and includes an FAQ data file.

## 🚀 Project Features

- Chatbot functionality using Python
- FAQ data management
- Voice-related Python module
- Modular project structure

## 🛠️ Technologies Used

- Python
- JSON

## 📂 Project Structure

```text
Chatbot/
│
├── app.py
├── chatbot.py
├── faq.json
└── voice.py
```

## ⚙️ Installation

1. Clone this repository:

```bash
git clone https://github.com/muthumookan005/Chatbot.git
```

2. Open the project folder:

```bash
cd Chatbot
```

3. Install the required dependencies according to your project requirements.

## ▶️ How to Run

Check the project code to identify the main application file and run it using Python.

Example:

```bash
python app.py
```
